# 러스틱타운 심청 예약관리 웹앱 — 프로젝트 기획서

> 최종 업데이트: 2026-03-10
> 버전: v1.0.0
> 배포: Vercel (Serverless)
> 데이터: Monday.com Board #18401306495

---

## 1. 프로젝트 개요

러스틱타운 심청 숙소의 예약·청소·운영을 하나의 웹앱으로 관리하는 시스템.
관리자(예약 CRUD, 대시보드, 숙소 관리)와 청소팀(청소 일정·가이드)을 동일 앱에서 역할별로 분리.

### 기술 스택

| 항목 | 기술 |
|------|------|
| 프론트엔드 | Single HTML + Tailwind CSS CDN + Vanilla JS (3,000+ lines) |
| 백엔드 API | Vercel Serverless Functions (Node.js 18+, ESM) |
| 데이터베이스 | Monday.com GraphQL API (Board 기반) |
| 배포 | Vercel (자동 배포) |
| 로컬 저장 | LocalStorage (프로그램 색상, 청소 일정, 비활성 숙소) |

### 파일 구조

```
rustictown-reservation/
├── index.html                  # 전체 앱 (HTML + CSS + JS)
├── package.json                # Node.js 설정
├── api/
│   ├── reservations.js         # GET  - 예약 목록 조회 (커서 페이지네이션)
│   ├── reservations-create.js  # POST - 예약 생성
│   ├── reservations-update.js  # PUT  - 예약 수정
│   └── reservations-delete.js  # DEL  - 예약 삭제
└── docs/
    └── PROJECT_SPEC.md         # 이 문서
```

## 3. 주요 기능

### 3.1 캘린더 (메인 화면)

#### 월간 뷰
- X축: 날짜 (1일~말일), Y축: 숙소 (17개)
- 예약 바: 프로그램별 색상, 게스트명·프로그램명 표시
- 주말/공휴일 하이라이트 (분홍 배경)
- 오늘 날짜 파란 하이라이트
- 월 이동 네비게이션 (◀ 2월 / 4월 ▶)

#### 주간 뷰
- 7일 단위 (큰 셀로 더 자세한 정보)
- 주간 이동 네비게이션

#### 드래그 선택
- **단일 드래그**: 방/기간 영역 선택 → 예약 폼 자동 열기
- **Ctrl/Cmd+드래그**: 비연속 다중 영역 선택
- **Ctrl/Cmd 키 릴리스**: 선택 완료 → 벌크 폼 자동 열기
- ESC: 전체 선택 해제
- 모바일: "⊞ 다중선택" 토글 버튼

### 3.2 예약 관리

#### 개별 예약 등록
- 게스트: 이름, 전화번호, 성별, 소속 (1~5+명)
- 숙소: 드롭다운 (비활성 숙소 제외, 프리미엄 ★ 표시)
- 기간: 체크인/체크아웃 날짜
- 프로그램: 드롭다운 (색상 자동 적용)
- 카테고리: B2C 포레스트캠프 / B2B 러케이션 / 기타
- 추가침구: 요(0~5), 이불(0~5), 베개(0~5)

#### 일괄 예약 등록 (벌크 폼)
- 다중 드래그/선택으로 여러 방 동시 등록
- 프로그램 공통 선택 → 각 방별 게스트 정보 입력
- 선택된 숙소명 배너 표시 (🏠 장미1, 국화1, ...)

#### 예약 상세/수정
- 캘린더 바 클릭 → 상세 모달
- 모든 필드 수정 가능
- Monday.com 실시간 동기화

#### 예약 삭제
- 확인 다이얼로그 → 삭제
- Monday.com 아이템 삭제 연동

## 4. API 설계

### 4.1 GET /api/reservations
- Monday.com 보드에서 전체 아이템 조회
- **커서 페이지네이션**: 500건씩 반복 조회 (1,000건+ 대응)
- 환불/취소 상태 자동 필터링
- 캐싱: CDN 60초, stale-while-revalidate 5분
- 날짜 변환: 타임라인 → day offset (March 1, 2026 기준)

### 4.2 POST /api/reservations-create
- 프론트엔드 폼 → Monday.com 아이템 생성
- 컬럼 매핑: 숙소, 타임라인, 프로그램, 전화번호, 성별, 소속, 카테고리, 추가침구

### 4.3 PUT /api/reservations-update
- 기존 아이템 컬럼 값 업데이트
- 동일한 컬럼 매핑 적용

### 4.4 DELETE /api/reservations-delete
- Monday.com 아이템 삭제

## 5. 날짜 시스템

### Day Offset
- 기준일: 2026년 3월 1일 (offset = 1)
- `toDayOffset(year, month, day)`: 날짜 → offset
- `fromDayOffset(offset)`: offset → {year, month, day}
- 서버(API)와 프론트엔드 동일한 offset 로직 사용
- UTC 기반 계산으로 서버 타임존 무관

### 공휴일 (2026)
- 신정, 설날(1/27~30), 삼일절(3/1~2), 어린이날, 부처님오신날, 현충일 등
- 주말·공휴일: 분홍 배경 하이라이트
